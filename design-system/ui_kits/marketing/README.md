# Marketing Website — UI Kit

Public-facing pulsecommerce.com. Editorial energy, big type, generous whitespace. Single-page kit covering home, features, pricing.

## Components

| File | Purpose |
| --- | --- |
| `Nav.jsx` | Top nav with logo, links, sign-in CTA |
| `Hero.jsx` | Editorial hero with display headline + sub |
| `LogoCloud.jsx` | Customer logo strip |
| `FeatureGrid.jsx` | Three-up feature cards |
| `Stat.jsx` | Big-number stat band |
| `Pricing.jsx` | Three-tier pricing table |
| `Footer.jsx` | Sitemap footer |
